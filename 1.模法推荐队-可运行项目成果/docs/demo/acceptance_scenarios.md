- `GET /api/v1/health`

- `POST /api/v1/recommend-models`
- `POST /api/v1/recommend-composition`

### 1. 县域新客首贷营销

- 输入：`我想筛一批县域新客，做首贷营销，最好能给出转化概率高的名单。`
- 预期意图：`customer_marketing`
- 推荐验收：Top5 包含首贷/新客、营销/转化相关模型或解释。
- 最近通过证据：Top1 `MKT_001 县域新客首贷转化预测模型`。

### 2. 农户小额贷款贷前风控

- 输入：`帮我做农户小额贷款的贷前准入风控，最好能识别欺诈风险并给出额度建议。`
- 预期意图：`credit_risk`
- 推荐验收：Top5 包含农户/小额/经营贷款，以及准入/反欺诈/额度相关模型或解释。
- 最近通过证据：Top1 `OFFICIAL_048 经营贷款贷前准入模型`。

### 3. 对公贷款贷后预警

- 输入：`我想提前发现对公贷款可能逾期的客户，并给客户经理一个预警名单。`
- 预期意图：`credit_risk`
- 推荐验收：Top5 包含违约/逾期/预警相关模型或解释。
- 最近通过证据：Top1 `OFFICIAL_028 小微企业违约概率B卡模型`。

### 4. 网点客流与排班运营

- 输入：`网点客流波动比较大，希望预测高峰时段并辅助排班，减少客户等待。`
- 预期意图：`operation_management`
- 推荐验收：Top5 包含网点/运营、客流/排班/资源/预测相关模型或解释。
- 最近通过证据：Top1 `OPS_035 运营成本分析优化模型`。
- 边界说明：官方 60 模型中没有精确的网点客流模型；默认主榜仍返回最近似的官方模型并展示低匹配。若 Demo 参考区命中精确网点客流模型，必须保持“Demo 参考”标识，不能计入官方结果、指标或组合。

### 5. 高价值客户流失挽留

- 输入：`请帮我识别高价值客户流失风险，输出需要重点挽留的客户名单和跟进优先级。`
- 预期意图：`customer_marketing`
- 推荐验收：Top5 包含流失/churn、高价值/价值相关模型或解释。
- 最近通过证据：Top1 `OFFICIAL_060 高价值存款客户流失预测模型`。

## 自动化脚本

默认 in-process 运行，不需要提前启动服务：

```powershell
python scripts\smoke_api.py
```

测试已启动的后端服务：

```powershell
python scripts\smoke_api.py --base-url http://127.0.0.1:8000
```

快速单场景检查：

```powershell
python scripts\smoke_api.py --limit 1
```

## 验收边界

- API smoke 验证后端端到端业务链路，不等价于浏览器截图验收。
- 前端浏览器验收仍需在本机启动前后端后，按下方 UI 清单逐项检查。
- 官方指标必须使用 `scripts\run_official_eval.py --all` 独立验证，不与 smoke 脚本混用口径。
