# 独立盲测数据目录

本目录只存放公开的无答案题目文件和冻结清单。私有答案文件必须命名为 `*.private.jsonl`，已经由 `.gitignore` 排除，不能提交到仓库。

正式盲测最低要求：

- 建议不少于 150 条，覆盖风控、营销、运营三个场景。
- 题目由未参与推荐算法开发的业务人员独立编写。
- 另一名人员独立复核可接受模型，可为一题标注多个等效模型。
- 题目不得包含模型 ID、完整模型名称或答案字段。
- 出题人与复核人不能相同。
- 冻结后任何文件变化都会导致评估拒绝执行。

详细字段、流程和命令见 `docs/eval/blind_evaluation_protocol.md`。
