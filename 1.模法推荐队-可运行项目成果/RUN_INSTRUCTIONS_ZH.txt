第16组：大模型驱动的模型市场智能推荐助手
========================================

一、运行前准备

1. Windows 10/11 x64。
2. 已安装并启动 Docker Desktop。
3. 确保 Docker Desktop 使用 Linux containers。
4. 默认端口 8000 和 3000 未被其他程序占用。
5. 首次构建 Docker 镜像需要联网；BGE-M3 已随压缩包交付，正常情况下不需要重新下载。

二、一键启动

1. 将整个压缩包完整解压，不要直接在压缩包预览窗口内运行。
2. 启动 Docker Desktop，等待 Docker Engine 就绪。
3. 双击根目录的 start-competition.bat。
4. 等待脚本完成模型校验、镜像构建和健康检查。
5. 启动成功后浏览器会打开：

   http://localhost:3000

后端健康接口：

   http://localhost:8000/api/v1/health

后端 API 文档：

   http://localhost:8000/docs

三、启动成功标准

脚本只有在下列条件全部满足时才会报告成功：

- 后端状态 healthy；
- 运行模式 competition_dense；
- BGE-M3 可用；
- 模型清单校验通过；
- 向量维度为 1024；
- 前端返回 HTTP 200。

系统不会在 BGE-M3 不可用时静默回退到轻量检索。

四、停止系统

双击：

   stop-competition.bat

停止操作不会删除随包交付的 BGE-M3，也不会删除本项目运行数据。

五、常见问题

1. 提示 Docker 不可用
   请确认 Docker Desktop 已经启动，并等待状态显示 Engine running。

2. 提示端口被占用
   关闭占用 8000 或 3000 端口的程序后重新运行。

3. 模型校验失败
   说明模型文件可能没有完整解压或压缩包传输损坏。请重新解压完整压缩包，不要手工替换模型文件。

4. Docker 镜像构建失败
   请检查网络连接以及 Docker Desktop 的代理设置，然后重新运行。

5. 启动时间较长
   首次构建依赖和首次加载约 2.30 GB 的 BGE-M3 均需要时间，后续运行会复用镜像、模型和向量缓存。

六、日志

启动日志保存在：

   .delivery\logs\

如需排查问题，请保留启动窗口中的错误信息和对应日志文件。
